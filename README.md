# ZIMSim
Simulation of a Deutsche Bahn (DB) train display (ZugInfoMonitor / ZIM)

<https://jan2903.github.io/ZIMSim>

## Data Sources
- **DB Stations (`stations.csv`)**: [StaDa - Station Data](https://developers.deutschebahn.com/db-api-marketplace/apis/product/stada) / [DB Open Data Haltestellendaten](https://data.deutschebahn.com/dataset/data-haltestellen) (DB InfraGO AG, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/))
- **Extended & International Stations (`stations_ext.csv`)**: Station database maintained in [Travel::Status::DE::IRIS](https://github.com/derf/Travel-Status-DE-IRIS) by Birte Kristina Friesel `<derf@finalrewind.org>` / DB Station&Service AG ([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/))
